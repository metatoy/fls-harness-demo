# design-system

The design system this app is built from, as data.

- **`pack.json`** — tokens, components, and rules in one machine-readable file. This is what the
  agent reads when it builds a prototype or a feature; it composes from these components rather
  than hand-rolling UI.
- **`tokens.css`** — the same tokens as CSS custom properties, for the app to import directly.
- **`REGENERATE.md`** — where this came from and how to refresh it.

Source: FLS Design System A — "Resolution" (FLS-DS-A-1.0). Generated 2026-09-10.
